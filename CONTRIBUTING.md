# Lavorare insieme

1. Leggi le attività e le proposte recenti, poi scegli un incarico distinto.
2. Crea un branch dedicato; evita modifiche parallele nella stessa directory locale.
3. Pubblica commit piccoli ma utili e una pull request, anche in bozza, per rendere visibile il lavoro.
4. Documenta le decisioni che serviranno agli altri. Spiega i controlli eseguiti e i limiti.
5. Chiedi revisione prima di integrare nel branch principale. Se le protezioni non sono disponibili sul piano GitHub, la convenzione resta valida ma non è tecnicamente imposta.

Per iniziare: [INIZIA-QUI.md](INIZIA-QUI.md). Le stesse regole operative si trovano in [AGENTS.md](AGENTS.md).
