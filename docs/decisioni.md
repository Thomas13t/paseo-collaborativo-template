# Decisioni condivise

Registrare qui soltanto decisioni che condizionano il lavoro del team: data, scelta, motivazione e collegamento all’attività o alla proposta.

La base iniziale prevede repository privato, lavoro su branch dedicati, revisione prima dell’integrazione e credenziali personali fuori dal repository. Confermare o modificare queste scelte quando viene definito il progetto concreto.
